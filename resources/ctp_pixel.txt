# Converted from DicomPixelAnonymizer.script (CTP / RSNA Clinical Trial
# Processor) - the Burned-in Annotation Library.
#
# CTP runs pixel masking as a separate pipeline stage from its metadata
# anonymizer, so this is a separate recipe from ctp_default.txt. Run it
# FIRST: these signatures match on Manufacturer, SeriesDescription,
# Modality and similar tags that the metadata pass hashes or removes.
#
#   dicom-deid-rs <input> <stage1> ctp_pixel.txt
#   dicom-deid-rs <stage1> <output> ctp_default.txt --var DATEINC ... --salt ...
#
# The intermediate directory holds clean pixels with fully identified
# headers: treat it as PHI and delete it when done.
#
# 188 CTP signatures -> 487 labels.
# 33 signatures mixed AND with OR under parentheses; the recipe
# format evaluates conditions strictly left to right with no grouping, so
# those were expanded into disjunctive normal form - one label per OR
# branch, each carrying the same regions. Regions from every matching
# label accumulate, so the result is equivalent.
#
# Translation notes:
#   - CTP tag numbers became DICOM keywords: filter fields resolve by
#     keyword only, and an unknown one silently never matches.
#   - .containsIgnoreCase -> contains (already case-insensitive)
#   - .equals / .equalsIgnoreCase -> equals (case-insensitive here; CTP's
#     .equals is case-sensitive, so matching is marginally broader)
#   - .startsWith(IgnoreCase) -> contains with a ^ anchor
#   - Values are regex-escaped, since `contains` compiles them as regexes.
#   - CTP's `SoftwareVersion` -> `SoftwareVersions` (the DICOM keyword).
#   - CTP's `[1018,1018]` is not a DICOM tag; treated as a typo for
#     (0018,1018) SecondaryCaptureDeviceManufacturerModelName.
#
# IMPORTANT (carried over from the CTP original): it is the user's
# responsibility to review images and confirm all PHI is removed. This
# library covers known regions in known devices, nothing more.
